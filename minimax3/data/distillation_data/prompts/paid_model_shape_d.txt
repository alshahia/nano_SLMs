block, no preamble.

GOAL
Produce N (instruction, response) pairs that teach a small model to think
briefly before coding. The reasoning must come BEFORE the code, separated
by a single blank line.

FORMAT (one JSON object per pair, in a JSON array)
{
  "instruction": "<1-3 sentence task in English, plain prose>",

}

REASONING RULES
- 30-200 words, ASCII only, no markdown headers, no bullet lists, no emoji.
- Reasoning comes BEFORE the code block, not interleaved.
- Reasoning should explain the APPROACH (what data structure / algorithm and
  why), not restate the instruction.
- Avoid stilted "Step 1: ... Step 2: ..." scaffolding.

CODE BLOCK RULES
- Three backticks followed by "python" open, code body, three backticks close.
- Inside the code block: imports, one or more functions, docstring with Args/
  Returns and at least one doctest, type hints on every public signature.
- AST-parses cleanly.
- Total response <= 500 tokens once tokenized.

DIVERSITY RULES
- Do NOT repeat the same problem twice.
- Cover algorithmic variety: recursion, DP, two-pointer, sliding window,

verbatim. Rephrase if needed.
