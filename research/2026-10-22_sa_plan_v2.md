> **Update 2026-10-22:** the OpenCode free tier is unusable at this scale. Minimax returns 429 after about 35 requests, beam-free is region-blocked, and the other `-free` ids are app-only. With user approval the teacher is now the **Gemini API free tier** (flash-lite, then flash, rotated on each model's daily free quota). Implemented in `scripts/teacher_client.py` + `scripts/sa2_teacher.py`. The rules below still apply: a free-only allowlist, abort on any non-free quota or billing signal, and every output executed and decontaminated.

Client rules (scripts/teacher_client.py, to be written):
- Endpoint `https://opencode.ai/inference/go/openai/v1`; key read from .env and never printed; honest user agent; a stable `x-opencode-session` id per task batch.
- **Hard allowlist of `*-free` model ids.** Abort on any reply whose `model` field is not on the list, and abort the run on any billing, quota or 402 error. It never retries onto another model.
- Modest rate: 1–2 requests at a time with backoff. Go docs say traffic is monitored for abuse, so this is not a bulk scraper.
- Prompts ask for short, simple code a 135M model can learn (no clever one-liners, no imports beyond stdlib).
- Every teacher output is executed and decontaminated before use; failures are dropped, not repaired.
- Fallback model: longcat-2.5-preview-free (also free). Never a paid model.

## 4. RL run 5 changes (after SA-5)

- **Loss normalization (Dr. GRPO):** scripts/rl_smollm2.py:345 divides each sequence's log-prob sum by its own length. That gives short correct answers a bigger per-token push and long wrong answers a smaller penalty, which favors short outputs and fits the one-line collapse. Fix: divide by a constant (max_new_tokens), behind a flag, and compare.
- DAPO dynamic sampling: resample groups whose rewards are all equal, up to a cap.
- No plain length penalty.
- Log per step: entropy, mean and p90 length, and the share of saturated (all-pass or all-fail) groups. Stop rules on entropy collapse.
