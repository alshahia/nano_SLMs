# E-63 — Laya-line L2: mixture pretrain → typed fine-tune (2026-09-22)

**Pre-registration:** research/EXPERIMENTS.md E-63 (user-approved; commit 92ea848).
**Question:** does a Laya-style generalist→specialist ladder beat E-62's direct
typed fine-tune at identical 37.16M params?
**Machine:** DESKTOP-MUO4QK5, Quadro RTX 4000 8 GB, venv python, fp16.

## Recipe
- Stage A: mixture pretrain, 3 epochs, 66,985 train / 7,442 heldout items from 7
  sources (boolq 9,427 · squad_v2 10,000 · snli 15,000 · mnli 20,000 · anli 10,000 ·
  scitail 5,000 · yelp5 5,000), same head/E-62 optimizer (lr 2.5e-5 / 1e-4, eff 64,
  cosine, clip 1.0, seed 42).
- Stage B: typed-decisions fine-tune, 4 epochs, E-62 recipe verbatim.
- Data bugs fixed en route (recorded in build_stats.json + git): yelp namespace
  (Yelp/yelp_review_full), squad_v2 author (rajpurkar/), scitail snli_format +
  gold_label column, option-text tuples silently batch-encoded by the tokenizer
  (fix: format in emit + strict str guard in pack_sequence).

## Gates (pre-registered)
- **G2 typed acc ≥ 0.60: PASS** (0.6585; +3.8 over E-62's 0.6205).
- **G1 mixture macro ≥ 0.74: FAIL as implemented** — eval_l2 measures the post-stage-B
  model: 0.6856. At stage-A exit it was 0.7478 (over the bar). Stage B forgetting:
  yelp5 0.512 → 0.22, ANLI 0.744 → 0.674. Both numbers recorded; the gate verdict
  stays FAIL.
- **G3 permutation-invariance ≥ 0.95: FAIL** (L2 0.385 / L1 0.325 on 200 reshuffled
  items) — rename sensitivity is a head weakness in both models.
- Overall verdict: **FAIL** (as pre-registered rule: all three gates must pass) with a
  validated capability ladder (+3.8 typed acc at identical params/cost).

## Calibration diagnostic
One global T fitted on 2,000 typed train items: T = 1.0797, ECE 0.0888 → 0.1282 (worse).
Second confirmation of the E-62 lesson: the typed head is already calibrated; do not
temperature-scale it.

## Levers for the next rung (L3, deferred per user decision)
1. Encoder pretraining (domain-matched) — the only lever that moves zero-shot transfer.
2. Stage B mixture replay (10-20%) to hold G1 at/above the bar.
3. Option-rename augmentation for permutation robustness.
4. ModernBERT-base 149M mid-rung (E-62 card: 0.646).
