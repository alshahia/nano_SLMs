# Shape A — Instruction → Code

This is the canonical "instruction tuning" format. The project's
`scripts/sft_data.py` (and `configs/sft_t1.yaml`) already consume it as
`(instruction, response)` JSONL.

The `seed.jsonl` in this folder was hand-crafted to demonstrate the schema
and tone. The bulk of `train.jsonl` was generated by a paid teacher model
(GPT-4o-mini / Claude Sonnet / DeepSeek V3 — see `meta/provenance.json`).

## Quick validation

```python
import json, ast
for line in open("train.jsonl", encoding="utf-8"):
    obj = json.loads(line)
    assert set(obj) == {"instruction", "response"}
    ast.parse(obj["response"])  # raises if response is not valid Python
```
